# Media Assets

This directory contains multimedia resources for the Ready Dev Start site.

## Key Assets

- **`Logo_IGA.png`** — The official logo. Used in the site header and as the page social preview thumbnail (og:image) across branding materials. Note: the page favicon is served from `/favicon.svg`, not this file.
- **`Purple Backdrop Normal.jpg`** — Default backdrop image for banners and promotional use.
- **`Logo animation HD.mp4`** — Animated logo for video intros.
- **`IGAPride.PNG`** — Pride edition of the logo.

## Other Assets

- **Badges** — `Badge_IGA_Level0–3_Progressive.png` — Level progression badges.
- **Role Banners** — `Banner_Cleric.png`, `Banner_Ranger.png`, `Banner_Rogue.png`, `Banner_Warrior.png` — Class/role-themed banners.
- **Charts** — `Game Industry Job Roles.svg`, `Video Games Genres Chart.svg` — Informational SVG graphics.
- **Templates** — Game Design Document, Press Kit, Media Kit, and One Pager templates (PDF/Markdown/CSV).

All assets are served from `/assets/` at the site root.
